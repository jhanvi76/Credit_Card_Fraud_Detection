# Credit Card Fraud Detection

A machine learning project that detects fraudulent credit card transactions using classification models, with techniques to handle severe class imbalance (undersampling and SMOTE oversampling).

## Overview

Credit card fraud datasets are highly imbalanced — genuine transactions vastly outnumber fraudulent ones. This project builds and compares classifiers on the raw imbalanced data, an undersampled dataset, and a SMOTE-oversampled dataset to see how each approach affects detection performance. The final model is saved with `joblib` for reuse.

## Dataset

- **File:** `creditcard.csv`
- **Rows/Columns:** 7,973 rows × 31 columns
- **Features:** `Time`, `V1`–`V28` (PCA-transformed features), `Amount`, and the target `Class` (`0` = normal, `1` = fraud)
- The dataset is **not included** in this repository due to size/privacy — download it and place it in the project root before running the notebook. A common source is the [Kaggle Credit Card Fraud Detection dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) (this project uses a smaller sample of the same schema).

## Approach

1. **Data cleaning** — checked for nulls, dropped duplicate rows, dropped the `Time` column.
2. **Preprocessing** — scaled `Amount` using `StandardScaler`.
3. **Baseline models** on the raw imbalanced data (Logistic Regression, Decision Tree).
4. **Undersampling** — balanced classes by sampling normal transactions down to the fraud count, then retrained both models.
5. **Oversampling (SMOTE)** — balanced classes by synthetically oversampling the minority (fraud) class, then retrained both models.
6. **Model export** — the Decision Tree trained on the SMOTE-balanced data is saved as `credit_card_model.pkl` and reloaded to demonstrate inference on a single transaction.

## Results

| Approach | Model | Accuracy | Precision | Recall | F1 Score |
|---|---|---|---|---|---|
| Imbalanced | Logistic Regression | 0.9987 | 0.667 | 1.000 | 0.800 |
| Imbalanced | Decision Tree | 0.9981 | 0.667 | 0.500 | 0.571 |
| Undersampled | Logistic Regression | 0.900 | 1.000 | 0.857 | 0.923 |
| Undersampled | Decision Tree | 1.000 | 1.000 | 1.000 | 1.000 |
| SMOTE Oversampled | Logistic Regression | 0.9987 | 0.997 | 1.000 | 0.999 |
| SMOTE Oversampled | Decision Tree | 0.9990 | 0.999 | 0.999 | 0.999 |

> Note: the undersampled results are based on a very small test set (only 25 normal transactions were sampled), so they should be read as illustrative rather than statistically robust.

## Getting Started

### Prerequisites
- Python 3.8+
- Jupyter Notebook or JupyterLab

### Installation

```bash
git clone <your-repo-url>
cd <your-repo-name>
pip install -r requirements.txt
```

### Usage

1. Download `creditcard.csv` and place it in the project root.
2. Launch the notebook:
   ```bash
   jupyter notebook Jhanvi_Fraud_Detection_Project.ipynb
   ```
3. Run all cells to reproduce preprocessing, model training, and evaluation. This also regenerates `credit_card_model.pkl`.
4. To use the saved model for inference:
   ```python
   import joblib
   model = joblib.load("credit_card_model.pkl")
   prediction = model.predict([[/* 29 feature values: V1-V28, Amount */]])
   print("Fraud Transaction" if prediction[0] == 1 else "Normal Transaction")
   ```
